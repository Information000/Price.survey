# Price.survey

競合店の売場で撮影した値札（プライスカード）の写真から、型番・価格・スペックを自動で読み取り、調査台帳にまとめてExcel・CSVで書き出すツールです。

対象カテゴリ：冷蔵庫、洗濯機、炊飯器、電子レンジ、オーブン、ドライヤー、ヘアアイロン、シェーバー、電動歯ブラシ、エアコン、テレビ、パソコン、プリンター

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages で公開している場合はそのURL）
2. 競合店・店舗名・調査日・カテゴリを入力
3. 値札の写真をドロップ（複数枚可）して「写真を読み取って台帳に追加」
4. 読み取った商品は自動で調査台帳に入る。赤い行（要確認）は「写真」ボタンで元の写真と見比べ、セルをクリックして修正
5. 「Excelで書き出し」で .xlsx ファイルを保存（CSVも出力可）

## Excelファイルの中身

- **調査台帳**：全項目。価格は円表示、実売価格（表示価格と特価の安い方）を黄色で強調、信頼度「低」の行は薄い赤。見出し固定・フィルター付き。
- **型番別比較**：同じ型番について競合店ごとの実売価格を横に並べ、最安値・最安店・最高値との差を表示。
- **出力情報**：出力日時、件数、絞り込み条件。

## 読み取りについて

- **無料モード（GitHub Pagesなどで開いた場合の初期設定）**：ブラウザの中で文字認識（Tesseract.js）を動かして読み取ります。費用はかからず、写真も外部に送りません。初回だけ文字データ（数MB）を読み込みます。AIによる読み取りより間違いが多く、特に低画質の写真では型番や価格を拾えないことがあります。
- **高精度モード**：Anthropic APIキーを入力するとAIで読み取ります（有料。キーはそのブラウザの localStorage にのみ保存）。Claudeの中で開いた場合は、キーなしでこのモードになります。
- 写真は自動で明るさ（レベル補正）と輪郭（シャープ）を補正してから読み取ります。
- 札の位置を探して1枚ずつ切り出し・拡大したものと、写真全体を9〜25区画に分けて拡大したものの両方を読みます。
- 同じ札を何度も読んだ結果を多数決でまとめます。0とD、8とBのような見間違えやすい文字の揺れは同じ型番として数え、多い方を採用します。
- 期間の書かれた価格を「特価」、それ以外を「表示価格」に振り分けます。型番が違う商品（2026年モデルと2027年モデルなど）は別の行です。
- 税抜と税込が10%で合わない行、型番が読めなかった行は「要確認」になります。
- LINEで送った写真は画質が落ちて型番が読めなくなります。カメラの元の写真か、LINEの「オリジナル画質」を使ってください。

## データの保存

台帳はブラウザの localStorage に保存されます。端末を移るときは「バックアップ(JSON)」と「読み込み」を使ってください。

## 注意

APIキーを含む状態でページを公開・共有しないでください。キーは各自のブラウザで入力する運用を想定しています。
