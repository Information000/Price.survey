# Price.survey

競合店の売場で撮影した値札（プライスカード）の写真から、型番・価格・スペックを自動で読み取り、調査台帳にまとめてCSVで書き出すツールです。

対象カテゴリ：冷蔵庫、洗濯機、炊飯器、電子レンジ、オーブン、ドライヤー、ヘアアイロン、シェーバー、電動歯ブラシ、エアコン、テレビ、パソコン、プリンター

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages で公開している場合はそのURL）
2. 競合店・店舗名・調査日・カテゴリを入力
3. 値札の写真をドロップ（複数枚可）して「写真を読み取る」
4. 読み取り結果を写真と見比べて修正し、「台帳に追加」
5. 「Excelで書き出し」で .xlsx ファイルを保存（CSVも出力可）

## Excelファイルの中身

- **調査台帳**：全項目。価格は円表示、実売価格（表示価格と特価の安い方）を黄色で強調、信頼度「低」の行は薄い赤。見出し固定・フィルター付き。
- **型番別比較**：同じ型番について競合店ごとの実売価格を横に並べ、最安値・最安店・最高値との差を表示。
- **出力情報**：出力日時、件数、絞り込み条件。

## 読み取りについて

- 単体で開いた場合は Anthropic API キーを入力して読み取ります（キーはそのブラウザの localStorage にのみ保存）。
- 通常の値札価格と「今週のお買得品」などの特価POPを分けて読み取り、同じ型番を1行にまとめます。
- 税抜・税込の片方しか読めない場合は、消費税10%でもう一方を計算します。
- 高精度モードでは写真を4分割して拡大読み取りします。

## データの保存

台帳はブラウザの localStorage に保存されます。端末を移るときは「バックアップ(JSON)」と「読み込み」を使ってください。

## 注意

APIキーを含む状態でページを公開・共有しないでください。キーは各自のブラウザで入力する運用を想定しています。
